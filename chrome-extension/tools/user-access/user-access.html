      Who is in each email and calendar configuration? (Einstein Activity Capture)

      Lists every user in each Einstein Activity Capture configuration, with no 500-user limit: users assigned directly, and everyone on a profile that is assigned. It also shows who is not connected, inactive users who are still assigned, users who are connected but have synced nothing, and users who have Einstein Activity Capture access but are in no configuration. Only “Connected” counts as connected: a blank status means the user has not connected yet. Every list can be downloaded for Excel. This reads every user, so it can take a moment in a large org.
