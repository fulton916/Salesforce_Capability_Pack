Error Tracer: read a debug log

Not connected
Before you start: turn on a debug log
  1. In Salesforce, open Setup and type Debug Logs in Quick Find.
  2. Under User Trace Flags, choose New. For Traced Entity Type choose User. For Traced Entity Name pick the person who will do the failing action (the person who repeats it). Set the Start Date and the Expiration Date so they cover the action (a trace flag can last up to 24 hours).
  3. Debug Level is a lookup, so typing a name finds nothing ("No matches found"). Use the search icon to pick a debug level that already exists, or choose New Debug Level (a small window opens) to make one.
  4. Set these levels: Apex Code at Debug or finer, Database at Info or finer, Validation at Info or finer, Workflow at Info or finer. Flows are only recorded when Workflow is at Info or finer.
  5. Ask the user to repeat what failed.
  6. Come back here and press Refresh the list, then pick the log.

Salesforce keeps these logs only for a limited time (system debug logs about 24 hours) and cuts off very large logs. Logs made by running Apex from the Developer Console or the command line use their own levels, so some areas may not be recorded. This page only reads logs that already exist. It never turns logging on or changes any setting.
